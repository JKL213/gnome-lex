Installation

  • Flatpak + flatpak-builder
  • GNOME SDK 51
  • Rust stable
  • Git

  1. Laufzeit und Rust holen

    Terminal
    $ flatpak install flathub org.gnome.Sdk//51 org.freedesktop.Sdk.Extension.rust-stable//26.08

  2. Quellcode klonen

    Terminal
    $ git clone https://github.com/JKL213/gnome-lex$ cd gnome-lex

  3. Bauen und installieren

    Terminal
    $ flatpak-builder --user --install --force-clean _flatpak build-aux/org.gnomelex.Gesetze.Devel.json

  4. Starten

    Terminal
    $ flatpak run org.gnomelex.Gesetze.Devel

Beim ersten Start BGB oder ZPO herunterladen – fertig.

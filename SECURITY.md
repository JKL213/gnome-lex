# Sicherheitshinweise (Security Policy)

## Unterstützte Versionen

Da sich gnome-lex in einer frühen Entwicklungsphase befindet, werden Sicherheitsupdates und Patches in der Regel nur für den `main`-Branch und aktuelle Versionen bereitgestellt.

| Version | Unterstützt |
| ------- | ------------------ |
| >= 0.1.x| :white_check_mark: |
| < 0.1.0 | :x:                |

## Sicherheitslücken melden

Wenn Sie eine Schwachstelle oder Sicherheitslücke in gnome-lex finden, melden Sie diese bitte **nicht** über öffentliche Issues.

Bitte senden Sie stattdessen eine E-Mail an: **janhk-koch@proton.me**.

Ich bemühe mich, jede Meldung so schnell wie möglich zu prüfen und zu beantworten. Bitte geben Sie in Ihrer E-Mail folgende Informationen an (soweit zutreffend):

- Eine Beschreibung der Schwachstelle
- Schritte zur Reproduktion (Proof of Concept)
- Mögliche Auswirkungen der Schwachstelle

Sollte es sich um eine berechtigte Meldung handeln, werde ich das Problem im privaten Rahmen beheben, bevor ein öffentlicher Patch veröffentlicht wird.

Vielen Dank, dass Sie dabei helfen, gnome-lex sicherer zu machen!
